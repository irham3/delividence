# Copywriting — Delividence

## Voice

Plain, calm, accountable. Write like a good project manager who can point to the original message. Prefer nouns and verbs over claims. The interface never speaks as if it owns a human decision.

## Do / do not

| Do | Do not |
| --- | --- |
| `2 client decisions are needed.` | `Our AI found critical blockers!` |
| `This request is not part of Baseline v1.` | `Scope creep detected.` |
| `Visual check: mobile layout found.` | `Verified by AI.` |
| `Client decision needed.` | `The agent will decide.` |
| `Your choice is recorded in this version.` | `Legally binding approval.` |

Avoid: AI-powered, seamless, unlock, transform, next-generation, future of work, autonomous, magic, effortless, or “single source of truth” as a headline. The exact model/SDK names occur only where factual proof is needed.

## Landing copy

| Location | Approved copy |
| --- | --- |
| Hero eyebrow | `One place for the material behind the work` |
| Hero headline | `The brief is more than the brief.` |
| Hero body | `Emails, notes, images, and calls become a record the project can actually use.` |
| Primary CTA | `Create a record` |
| Secondary CTA | `See a sample` |
| Scene 2 | `Watch the material become a record.` |
| Scene 3 | `The record asks for a decision, not another conversation.` |
| Scene 4 | `New work takes a separate path.` |
| Scene 5 | `Put the proof beside the promise.` |
| Scene 6 | `A record that keeps its place.` |
| Final CTA | `Give the work a record worth returning to.` |

## Product copy

| Context | Copy |
| --- | --- |
| Workspace | `Good morning, Maya.` / `Three records need a decision.` |
| Empty workspace | `No decisions need you right now.` / `Create a record when new material arrives.` |
| Intake title | `Start with the material you already have.` |
| Intake help | `Add a brief, email export, call recording, chat export, screenshot, or video reference.` |
| Intake action | `Read the material` |
| Question title | `Ask only what the record cannot answer.` |
| Waiting state | `Waiting for the client’s reply.` |
| Baseline ready | `Ready for client review` |
| Client header | `[Record name] — review the working agreement` |
| Client helper | `No account required. Your choices are recorded in this version.` |
| Change title | `New request from [client]` |
| Change classification | `This request is not part of the approved baseline.` |
| Proof helper | `Visual checks assist the review. The client decides.` |
| Preference helper | `Policies guide your drafts. They never replace a client’s words.` |

## Buttons and system messages

Use action-specific labels: `Review client link`, `Send review link`, `Open source`, `Create change request`, `Add evidence`, `Approve baseline`, `Accept`, `Request changes`.

Error messages name the problem and a recovery path:

- `This link has expired. Ask Maya for a new review link.`
- `We could not quote this text from the source. It is saved as a proposal, not a client statement.`
- `A client decision is still needed before this baseline can be approved.`
- `This evidence could not be opened. Upload it again or attach a different link.`
