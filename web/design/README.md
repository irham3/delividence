## The non-negotiables

- The interface feels like a calm working record, not an “AI product”.
- Saffron is one brand signal, not a decorative color system.
- Product behaviour is shown through sources, decisions, versions, and evidence—not vanity metrics or chat bubbles.
- A model may propose; a person resolves client conflicts, approves a baseline, decides a change, and accepts work.
- Use real product screens in the landing. Do not replace them with generic mockups after implementation begins.
