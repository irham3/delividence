# Motion Media Plan

## What to make now

No generated marketing video is required for the product UI or landing. The approved design is based on live DOM surfaces and GSAP motion, which is the correct implementation for visual sharpness, low load cost, responsive reflow, and reduced-motion support.

## What to record after the app runs

Create a real 12–15 second silent product loop from the deployed app for optional use below the landing fold or in the Devpost page:

1. Source material enters the record (0–3s).
2. Three questions appear; client opens secure link (3–6s).
3. Client chooses an answer; workflow resumes (6–9s).
4. Baseline becomes active (9–11s).
5. New request routes to change decision and evidence aligns to a criterion (11–15s).

Export 1440×900 WebM + MP4, plus a WebP poster. Muted autoplay is optional only below the fold; pause when out of view; offer playback controls. Use the actual app, never a fabricated “agent worked” animation, for hackathon proof.

## Demo-video alignment

The official ~4-minute video should open with the working product in 10–15 seconds, then follow the sequence in [09-IMPLEMENTATION-PLAN.md](09-IMPLEMENTATION-PLAN.md). The product loop is a supporting transition, not a substitute for live Google Cloud deployment proof.
